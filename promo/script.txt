大家好，录口播最怕什么？忘词。

低头看稿，眼神就飘了；提词器 App，动不动就要订阅。

我给自己做了一个免费的——叶哥提词器，今天开源给大家。

它的核心能力就一句话：台词跟着你的语速走。你念到哪，它滚到哪；念快了它就快，停下来它就等，跳读几句它还能自动接上。

这是多稿件库——所有稿子存在你自己的电脑上。电脑上写的稿子，手机扫个码，直接就能用，五秒内自动同步。

iPad 上也能跑。装一次证书，语音跟随便用。

零订阅、零云端、数据完全在本地。整套东西就一个网页加一个 Python 小脚本。

GitHub 搜索 yege-teleprompter，地址在评论区。让台词追着你走，而不是你追着台词跑。
